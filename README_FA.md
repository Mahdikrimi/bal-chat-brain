# BAL CHAT BRAIN 1.2 — نسخه آزمایشی آموزش‌دیده

این بسته شامل مغز آزمایشی بال چت، حافظه محلی، کد آماده‌سازی داده و مدل TinyCharLM است.

## آموزش

```bash
pip install torch
python prepare_data.py
python train.py
python brain.py
```

مجموعه فعلی شامل ۳٬۳۷۸ جفت پرسش و پاسخ فارسی است. داده‌ها موضوع‌هایی مانند گفت‌وگو، دانش عمومی، علوم، ریاضی، برنامه‌نویسی، وب، مطالعه و امنیت را پوشش می‌دهند.

## نکته مهم درباره کیفیت

آموزش با موفقیت اجرا شده، اما مدل کوچک هنوز در پاسخ آزاد خروجی نامفهوم تولید می‌کند. به همین دلیل استفاده خودکار از مدل زبانی در `brain.py` پیش‌فرض خاموش است؛ حافظه و پاسخ‌های پایه کار می‌کنند. پایین‌آمدن loss به معنی پاسخ‌گویی درست نیست. این پروژه هنوز مدل مستقل هم‌سطح ChatGPT نیست و روی سرور آنلاین نصب نشده است.
